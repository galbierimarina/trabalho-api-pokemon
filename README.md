O projeto consiste em uma aplicação web desenvolvida utilizando puramente HTML, CSS e JavaScript, sem o uso de frameworks, cujo objetivo é consumir dados em tempo real de uma API pública. Escolhi a PokeAPI para trazer um catálogo clássico de desenhos e personagens dos anos 90 e 2000. Como podem ver na tela, a interface apresenta um layout organizado, com estética temática, exibindo a imagem, o nome e o tipo de cada Pokémon de forma automatizada.
